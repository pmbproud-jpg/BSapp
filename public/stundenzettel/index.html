Stundenzettel-Generator

Stundenzettel → PDF · Daten werden nur in diesem Browser gespeichert

Gilt für alle Personen unten. Tipp: Speichern Sie regelmäßig eine Sicherung — bei „Browserdaten löschen" gehen ungesicherte Einträge verloren.

Die Baustellen-Liste gilt für alle Personen. Uhrzeiten wählen Sie aus den Listen (Stunde : Minute). „Stunden" = (Bis − Von) − Pause. Anfahrt wird separat gezählt.

Eine Person → eigener Stundenzettel (einzeln). „Alle Personen" → ein PDF, eine Seite pro Person.
